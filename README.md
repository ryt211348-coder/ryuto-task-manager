# りゅうと タスク管理ダッシュボード

複数事業（2ch / Popteen / スマホ / 美容ちゃん 等）のタスクを、**日 / 週 / 月**で一発閲覧し、
**誰のFBが終わって／終わってないか**・**進捗率（健全度）**を可視化するWebアプリ。
将来的に Discord 連携（リアクション確定＋発言の自動反映）と GitHub Actions 自動化を載せる。

実装計画の全体像は `docs/` の上位、plan ファイル参照。本READMEは現行（Phase 1）の使い方。

## いま動くもの（Discord・AIなし・全部ブラウザ完結）
- **カレンダー（月）＋ 右に縦の時間割（7:00〜20:00・各ブロックに進捗バー）** のレイアウト（`docs/index.html`）。ビルド不要
- カレンダーで案件の締切・私用を一覧 → 日をクリックでその日の「📌本日のアクション＋時間割」を表示
- 上部に**キャパ要約バー**（必要/使える/日曜休める可否）＋**今日の台本ノルマ ＋/−**（超えると🔥で褒める）
- **🎯 今日のアクション**（中核）：納期に対する遅れから自動で3分類
  - 🟡 **進捗確認すべき**＝ワーカーにボールがあり納期に遅れている → 「○○さんに進捗確認」
  - 🔴 **あなたが上げる**＝自分にボールがある企画/台本（2ch/sma のボトルネック）
  - ⚪ **待ち（放置でOK）**＝ワーカー対応中で予定通り（投げ待ち）
  - カテゴリ別ルール（`config.cat_rules`）：**Popteen=早めに催促 / 2ch・スマホ=投げたら放置**
- **📅 キャパシティ・プランナー**：目標本数×時間単価から週の必要時間を逆算。**企画/台本を工程分割**、**私用予定（＋予定）を入れるとその分タスク可能時間を控除**、過不足と「日曜午後を休めるか」を判定、1日の目安（りゅうとん企画◯・台本◯）を提示
- **🏆 実績・応援**：今日/今週やった本数を＋/−で記録。目標達成で✅、**予定より多くこなすと🔥で褒める**
- 上部メトリクス：消化率・新規流入・FB待ち・締切逼迫・割り込み
- 担当者別ボード（プルダウン展開）：誰待ち・進捗率・健全度%・工程ごとの状態
- 工程をクリックで状態変更（未着手→対応中→完了→…）。全工程完了で案件は自動「完了」
- 案件リスト（日/週/月フィルタ、完了率バー）
- 保存：ブラウザの localStorage。GitHub設定をすれば API で `tasks.json` に自動コミット（同期）

「誰に進捗確認すべきか」は **ボールの所在（次に動くべき工程の担当者）×納期遅れ** で判定（`docs/js/metrics.js` の `ballHolder` / `actionItems`）。Discord も AI も使わない。

## ローカルで開く
```
cd "タスク管理　6月"
python3 -m http.server 4178
# ブラウザで http://localhost:4178/docs/index.html
```

## GitHub Pages で公開（ブラウザで一発閲覧）
1. このフォルダを GitHub リポジトリに push
2. Settings → Pages → Source: `main` / フォルダ `/docs`
3. 公開URL（`https://<user>.github.io/<repo>/`）を開く

## データ保存先（真実の源）= `tasks.json`
- リポジトリ直下の `tasks.json`。git履歴がそのまま「いつ誰のFBが解消したか」の変更ログになる
- 画面右上 ⚙ から GitHub設定（owner / repo / branch / path / **fine-grained PAT**）を登録すると、
  編集が自動で `tasks.json` にコミットされる（複数デバイスで共有可能）
  - PAT は **対象1リポジトリ・contents:write** に絞る。localStorage に保存される点に注意
  - 未設定でもローカル保存で完全に動作する

## データ構造（3階層）
案件(project) → 依頼(assignment, 担当者単位) → 工程(checkpoint)。
- 案件 status: `active / on_hold / done / canceled`（保留・中止・割り込みを表現）
- 工程 state: `not_started / in_progress / done / na`
- 健全度% = 工程完了率 ＋ 納期までの残時間 ＋ 担当者の進行ペース の合成（`docs/js/metrics.js`）

## 次フェーズ（任意・軽量）
- **毎朝の自動リマインド**：GitHub Actions cron が `tasks.json` から「今日のアクション」を計算し、
  Discord webhook に1メッセージ投稿（**Bot不要・Message Content Intent不要・Anthropic不要**、URLを1つ登録するだけ）。
  「毎回頼まなくても、朝に今日やること／誰に確認すべきかが届く」を最小コストで実現。
- 必要になったら：ブラウザ通知（タブを開いている間の1時間毎リマインド）、進捗ペースの自動学習。

※ 当初検討した「Discord発言/過去ログのAI自動反映」は、コストと手間が見合わないため見送り。
   状態更新は画面の工程クリック（手動・確実）で行う。
